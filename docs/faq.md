## 关于仓库

### 这个仓库是什么？

这是 Multisource HL Copy 的公开展示材料包，介绍产品关注的问题、能力表达和阅读体验。它包含文档、概念图与静态合成例子。它与私有生产实现的范围不同，详细边界见 [PUBLIC_SCOPE.md](../PUBLIC_SCOPE.md)。

### 下载后可以开始交易吗？

不可以。仓库没有交易运行时、账户接入、密钥配置或部署入口。阅读 JSON、查看图片或运行公开材料检查，都不会连接交易账户或提交委托。

### 为什么保留能力介绍，却不公开实现？

能力介绍帮助访问者理解使用场景、可见结果和产品取舍。它不需要公开执行算法、具体参数或运行环境。读者可以讨论表达是否完整；不能从描述直接得出私有系统已经实现或验证这些能力的结论。

### “公开仓库”是否意味着所有材料都可以任意使用？

使用条件取决于适用许可，不由是否可以公开访问决定。请阅读根目录的 [LICENSE](../LICENSE) 及其中指向的历史许可说明。展示材料也不授予私有代码或服务的访问权。

## 关于图示与合成数据

### 示例是不是把真实日志里的名称换掉了？

不是。本次展示中的情境、来源、资产、状态与数值是为说明问题而构造的虚构内容，不是重命名的真实日志，也不是真实账户记录的匿名化导出。它们明确标为 **SIMULATED / 合成示例**。

### SOURCE_A 或 ASSET_X 能对应到真实账户或资产吗？

不能。它们是虚构标签，不提供真实钱包、账户、市场或资产的映射。不要把这些标识替换成真实地址来尝试运行示例；本仓库没有这样的运行功能。

### 图片是产品的实际管理界面吗？

不是。图片是公开介绍用的说明画面，用来表达流程与信息关系。不能据此推断存在相应的网页控制台，或图中状态来自正在运行的服务。

### JSON 是生产 API、配置模板或可导入的策略吗？

不是。[场景](../examples/scenario.json)、[报告](../examples/report.json)与[风险事件](../examples/risk-event.json)仅供阅读。字段名称和结构不承诺与任何生产接口兼容，也不是可执行配置或策略规则。

### 示例中的数值可以用来比较性能或收益吗？

不可以。合成数值只为阅读与排版服务，没有真实测量基础。它们不能用于计算实际跟随质量、延迟、可用性、收益或风险，也不能用来挑选真实交易来源。

## 关于能力与证据

### 功能页能证明哪些能力已上线吗？

不能。[功能说明](features.md)是产品能力描述；示意图与样例是表达方式。判断私有功能是否已实现、部署或实盘验证，需要与明确版本、环境和评估范围对应的另行证据。

### 为什么这里没有生产测试数量和性能基准？

当前公开包不提供这些材料。**未纳入不等于已被否定，也不等于已被本包证实。** 无论对旧数字持何种判断，都不能用当前合成示例替代原始证据。公开证据边界见 [验证范围](testing.md)。

### 公开检查脚本验证什么？

在仓库根目录、使用 Python 3.10 或更新版本运行：

```bash
python3 tools/check_public.py
```

该脚本检查公开展示包本身，具体检查项以脚本内容为准。它不是交易引擎测试、回测、实盘实验或安全审计。检查通过，也不能证明交易会正确执行、凭证安全、风控有效或报告数值真实。

### 一个风险示例显示“已处置”，能说明真实风险已消除吗？

不能。示例状态是虚构情境的一部分。它既不证明市场上的动作会按时完成，也不建立真实事件与处置动作的固定对应关系，更不能保证损失上限。

## 关于历史、反馈与报告

### 替换当前 ZIP 能删除以前已经公开的内容吗？

不能。更新当前文件不会自动改写 Git 历史、已有发布附件、分支、派生副本、缓存、截图或其他人的下载。本包只描述当前提供的材料，不能承诺旧公开内容已经消失；适用的既有许可权利也不能仅因更新 ZIP 被视为不存在。

### 可以贡献什么？

欢迎改进文档、翻译、示意图的可读性和完全虚构的场景。贡献应帮助访问者理解能力与限制，不加入生产实现、真实配置、地址、账户记录或日志。详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

### 想证明某个问题，可以在公开讨论里贴自己的日志吗？

不要提交真实日志、账户截图、凭据或可识别来源的记录。使用最小的虚构情境说明文档问题即可；合成例子仍需明确标注其性质。

### 如果发现疑似敏感内容，应在哪里报告？

按照 [SECURITY.md](../SECURITY.md) 的说明处理。只有在仓库确实启用了私密漏洞报告时才使用该入口；否则先请求建立私下沟通渠道，不要把秘密或其详细位置贴到公开讨论里。本仓库不在此虚构联系邮箱或报告服务。
