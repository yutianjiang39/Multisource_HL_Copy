# 功能说明

[English](en/features.md) · [项目首页](../README.md) · [场景导览](showcase.md) · [常见问题](faq.md)

本页介绍产品关注的能力、使用场景和可见结果。**这些是能力说明，不是从本仓库验证出的实现、部署或实盘状态。** 本仓库提供文档、概念示意图和合成数据，不包含可连接账户、接收实时行情或提交委托的交易系统。

图示与示例均标为 **SIMULATED / 合成示例**。其中的来源、资产、状态和数值全部虚构；示意画面也不是生产界面截图。公开材料的边界见 [PUBLIC_SCOPE.md](../PUBLIC_SCOPE.md)，证据的阅读方式见 [验证范围](testing.md)。

以上阅读入口展示的是信息表达方式，不是可操作的控制台或已运行的功能演示。

## 1. 多来源组织

**使用场景：** 使用者希望在同一份状态视图中理解多个来源的活动，而不必在零散记录之间反复确认上下文。

**能力说明：** 将来源身份、相关资产和活动状态放在可辨认的上下文中，让汇总报告仍能说明某条记录属于哪个来源。多来源视角也应帮助使用者发现需要进一步理解的差异。

**公开可见：** 以 SOURCE_A、SOURCE_B 与 ASSET_X、ASSET_Y 表示完全虚构的来源和资产，观察来源标签是否清楚、摘要能否追溯到对应场景。

**边界：** 并列展示多条来源记录，不表示它们会同时产生交易，也不说明资金分配、执行优先级或来源冲突的处理方式。合成标识不是钱包地址或可交易资产配置。

## 2. 委托与持仓过程

**使用场景：** 来源出现委托、调整交易意图或改变持仓后，使用者希望知道相关记录目前处于什么状态。

**能力说明：** 围绕挂单、修改与撤销委托、持仓增减和结束持仓等常见活动，说明来源动作与相关响应。委托过程、持仓变化和最终可观察结果应能够分别阅读；来源已经发生某个动作，并不等于本方一定获得了同样的结果。

| 阅读对象 | 希望表达的内容 |
|---|---|
| 委托出现 | 来源有一项新的交易意图，以及与之相关的响应描述 |
| 意图变化 | 相关记录发生变化，读者能够理解前后关系 |
| 委托结束 | 当前记录如何描述委托的结束状态 |
| 持仓变化 | 持仓摘要发生了什么变化，是否存在待关注的差异 |
| 结果未明 | 现有信息不足以确认结果，不能把它写成已完成 |

**公开可见：** [跟随场景](showcase.md#旅程一读懂一次委托过程)与[合成场景数据](../examples/scenario.json)展示这类信息的组织方式。

**边界：** 公开材料不展示委托构造、数量计算、执行路径或确认机制；也不证明真实委托可以成交、完全跟随或保持相同盈亏。

## 3. 风险信息与干预结果

**使用场景：** 账户活动出现值得关注的情况时，使用者需要看懂提示、处置描述和仍未解决的问题。

**能力说明：** 风险信息应与相关来源、资产或账户情境联系起来。暂停新增活动、撤销委托、处置持仓等结果，需要用可理解的文字说明；尚未确认的结果也应被明确保留。

**公开可见：** [风险事件示意](showcase.md#旅程三阅读风险提示与处置结果)和[合成事件数据](../examples/risk-event.json)展示如何区分事件描述、记录的动作与待确认事项。

**边界：** 示例不建立真实事件与处置动作的一一映射，不公开阈值、计算方式或控制顺序。风险能力的描述不构成损失上限、成交结果或账户安全保证。

## 4. 配置与范围变更

**使用场景：** 使用者希望调整关注的来源、资产范围或其他产品设置，同时理解这项修改可能影响哪些活动。

**能力说明：** 对外说明应能区分期望的修改、当前呈现的设置，以及与此次变更有关的结果记录。这样，使用者可以围绕“改了什么、影响哪里、还有什么待确认”进行复核。

**公开可见：** 本页说明变更体验关注的信息；仓库不包含真实参数表或可执行的配置样例。

**边界：** 这里没有管理入口，不能应用修改。哪些字段可改、何时生效、需要何种操作条件以及如何处理失败，都不能从公开示意中推导。

## 5. 异常信息与人工复核

**使用场景：** 状态缺失、记录存在差异，或报告无法完整解释某次活动时，使用者需要知道哪些结论还不成立。

**能力说明：** 将已知信息和未决问题分开表达，保留相关上下文，帮助人工复核。异常摘要应指出需要查看的事实，而不是把推测写成确定的原因。

**公开可见：** 场景与报告示例中的状态差异、关注事项和结果说明，供读者评估表达是否足够清楚。

**边界：** 这些材料不包含故障恢复方案、重试规则或运行处置指南，也不表示所有异常都能自动解决。

## 6. 报告与提醒

**使用场景：** 使用者无法持续查看所有活动，需要一份可以快速阅读、又能指出重点的摘要。

**能力说明：** 报告围绕来源活动、未结束委托、持仓摘要、相关差异和需要关注的事项组织信息。事件提醒侧重单个值得查看的变化，周期摘要侧重整体阅读体验。读者应能区分一段活动的总体情况与某条记录尚未确认的结果。

**公开可见：** [报告示意](showcase.md#旅程四阅读一份活动报告)与[合成报告数据](../examples/report.json)。报告中的解释性文字只用于展示表达方式，不是对真实账户的诊断。

**边界：** 本仓库不会发送提醒，也没有实时报告服务。合成汇总值不能当作交易记录、收益统计、延迟测量或可靠性证据。

## 7. 演练与场景讨论

**使用场景：** 在讨论新来源或产品设置时，先明确希望观察的状态与报告内容。

**能力说明：** 演练可以帮助参与者讨论预期行为、识别遗漏的场景，并检查状态表达是否容易理解。

**公开可见：** 本仓库提供的是静态合成示例，适合逐步阅读或在评审中引用；它们不是可运行的模拟交易程序。

**边界：** 阅读一个虚构场景，不等于完成了回测、仿真或真实市场验证。示例不模拟流动性、成交概率、手续费、保证金或收益。

## 8. 可追溯的解释

**使用场景：** 读者在摘要里看到一条异常或差异，希望找回与之有关的来源和场景。

**能力说明：** 通过清楚的标签与相关描述，将总体摘要和具体情境联系起来，支持讨论“发生了什么、目前知道什么”。

**公开可见：** 文档、示意图与合成数据之间的对应关系；这是公开材料本身可以检查的可读性。

**边界：** 本仓库不提供生产日志、逐笔成交、账户历史或内部记录格式。公开场景无法替代对真实活动的调查。

## 访问者可以评估什么

| 可以从本仓库评估 | 不能仅凭本仓库评估 |
|---|---|
| 产品描述是否清楚、前后一致 | 私有功能是否完成、部署或实盘验证 |
| 来源、事件与结果是否容易区分 | 多来源执行和数量计算是否正确 |
| 示例是否标明合成性质与信息边界 | 真实成交速度、跟随质量或长期可用性 |
| 风险提示与关注事项是否容易理解 | 风控能否限制真实损失 |
| 中英文、图示与数据是否对应 | 任意市场条件下的盈利能力 |

## 常见问题

**可以直接连接账户或启动交易吗？**  
不可以。这是展示材料包，没有交易运行时、账户接入或可执行的生产配置。

**示意图是实际产品界面吗？**  
不是。它们是为说明信息关系而制作的示意画面，不代表现有管理面板或实时服务。

**产品背景与公开支持范围是什么？**  
产品背景是多来源的永续合约跟随。公开材料围绕委托、持仓、风险与报告展开，不能据此推导任何具体市场、订单类型或第三方服务的兼容性承诺。

**某个来源动作为什么没有对应交易结果？**  
公开示例可能只表达某段情境。不能把“来源出现动作”“记录了响应”“结果得到确认”视为同一件事，也不能由静态示意推断私有系统的决策原因。

**如何提出有用的反馈？**  
指出文档位置、难以理解的表述或缺失的阅读场景，并使用虚构标识说明问题。真实账户资料和运行记录不属于公开反馈所需材料。

**可以怎样使用这些材料？**  
适用条件见 [LICENSE](../LICENSE) 和 [公开范围](../PUBLIC_SCOPE.md)；功能说明不授予私有实现的访问权。
