# 证据与验证边界

[English](en/testing.md) · [返回首页](../README.md)

本页说明读者能从这个公开仓库独立核对什么。它不是私有系统的测试报告，也不公布生产测试数量、部署状态、运行日期或时延结论。

## 三类材料不能混用

| 材料类型 | 本版中的例子 | 可以说明什么 |
| --- | --- | --- |
| 能力描述 | README、功能说明、职责概览 | 项目关注的需求和产品表达 |
| 合成示例 | SVG、JSON、场景导览 | 一种阅读方式或信息呈现方式 |
| 可执行的本地检查 | 文件清单、链接、样例与图示检查 | 当前公开文件满足被检查的规则 |

前两类不构成真实成交或生产可靠性的证据。第三类的通过，也不能证明私有引擎、交易策略、订单幂等性、恢复能力或风控效果。

## 本地检查

在仓库根目录使用 Python 3.10 或更高版本：

```bash
python3 tools/check_public.py
python3 tools/package_public.py --output ../Multisource_HL_Copy-public.zip
```

检查器以 [public-files.txt](../public-files.txt) 为发布清单，检查公开路径、相对链接、合成 JSON 标记、SVG 安全结构和若干高置信度敏感模式。打包器只包含清单中的文件，不打包 Git 历史，并对归档内容再次检查。

检查不访问交易所、不读取账户、不运行交易模拟，也不分析私有代码。它不能识别所有商业秘密、语义泄漏、图片中的含义或已经存在的公开历史；仍需人工审阅。

仓库自带的 CI 只重复这一公开内容检查。工作流文件存在，不代表远端 CI 已运行。

## 如果将来公开验证摘要

任何新的测量摘要都应先经过独立披露审查，再说明：

- 测量的是哪一类结果、采用什么定义。
- 样本选择、遗漏样本与适用范围。
- 观察结果与设计目标之间的区别。
- 未覆盖的环境、负面结果与不确定性。
- 数据是否仍适用于正在讨论的版本。

不要用“测试通过”推导“无缺陷”，不要将有限样本扩展为普遍成交、零重复或收益保证。当前版选择不发布这些生产数据。

## 本版验收关注点

中英文含义一致；图片、文字与 JSON 都明确标为合成；未确认事项不被写成完成；所有相对资源能打开；旧接口轮廓不随包发布；打包结果与发布清单一致。上述检查服务于公开材料的质量和披露边界。
